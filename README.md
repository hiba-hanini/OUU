# OUU

This repository gathers small exercises and notes for the Optimization under Uncertainty (OUU) coursework.

## Contents

- [skater_ex/](skater_ex/): Skater MDP exercise, a compact stochastic optimal control problem on a grid world.
- [intern/](intern/): smaller internal experiment on optimal decision thresholds.

## Quick start

```bash
cd OUU/skater_ex
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python3 main.py
```

See the project-specific READMEs in each folder for more details.
